# Changelog

## [1.0.0] - 2026-11-10

First release on GitHub of the 10 datasets published on [aptdot.com/datasets](https://www.aptdot.com/datasets/), each with a JSON Schema and an automatic validation check:

HTTP Security Headers, Synthetic RBAC & User Permissions, JWT Claims & Signed Test Tokens, MCP Server Configs, CI/CD Pipeline Templates, Synthetic FHIR R4 Patient Records, E-Commerce Product Catalog, IANA Time Zones (tzdb 2026e), ISO 3166-1 & ISO 4217 Country and Currency Codes, and Design Color Tokens.

[1.0.0]: https://github.com/mkchd25/aptdot-datasets/releases/tag/v1.0.0
